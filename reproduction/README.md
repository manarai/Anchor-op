# Reproduction of manuscript figures

Every figure referenced in `../MANUSCRIPT.md` is reproduced by one script in this directory. Scripts are numbered by manuscript figure order and are independent (no shared state between them beyond the pickled measurement bundles in `../results/` and the raw h5ads listed under **Data dependencies** below).

## Quick start

```bash
cd /path/to/anchor-op-source
PYTHONPATH=src python3 reproduction/run_all.sh    # runs all scripts sequentially
# or, for one figure at a time:
PYTHONPATH=src python3 reproduction/07_figS3_estimator_simulation.py
```

Output PNGs land in `../manuscript_figures/`. Each script prints its output paths and any numeric summary it computes.

## Data dependencies

Two categories of data:

**Public h5ads** (download once, ~4 GB total):
- `examples/data/K562_essential_normalized_singlecell_01.h5ad` — Replogle 2022 K562 essential-gene Perturb-seq. Source: <https://gwps.wi.mit.edu>, Figshare Plus deposit 20029387.
- `examples/data/rpe1_normalized_singlecell_01.h5ad` — same source, RPE1 essential.
- `examples/data/jost2020/GSE132080_10X_{matrix,barcodes,genes}.tsv.gz` + `GSE132080_{cell_identities,sgRNA_barcode_sequences_and_phenotypes}.csv.gz` — Jost et al. 2020, GEO GSE132080.

**Local raw** (for `02_fig2_k562_aggregate.py` only, not required for other figures):
- The 84K K562 noncoding-element aggregate 10x mtx + CRISPR analysis. Path is set at the top of the script as `DATA_ROOT`; edit to point at your local copy.

**Measurement bundles** (regenerated by scripts 03 and 04, then loaded by scripts 05, 10):
- `../results/k562_essential_measurement.pkl`
- `../results/rpe1_essential_measurement.pkl`

If you have not run scripts 03 and 04 yet, run them first (or drop into `results/` bundles you already have from prior runs). Scripts 05 and 10 will error clearly if the bundles are absent.

## Provenance and sanity checks

Each script emits a numeric summary to stdout. Compare against §3 of the manuscript. All scripts are deterministic (fixed random seeds). Running the full `run_all.sh` on a clean checkout should reproduce every manuscript figure and every reported number.
