# obsolete/ — superseded figures

These PNGs reflect a superseded simulation scale and manuscript framing.
They correspond to earlier drafts that used the published-amplitude
simulation (α_S = 1) and reported density-based projections, and to
older layouts that predate the target-held-out nested-CV framing.

**Do not reuse these figures.** They are kept only so that git history
remains lossless. New figures live one directory up.

If you need to regenerate anything for a retrospective, do it against a
git checkout of the pre-restructure commit and copy the result to a
new file rather than replacing the current numbered figures.
